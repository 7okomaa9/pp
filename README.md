# Ashraf StudyHub — GitHub Pages

هذه نسخة ثابتة من StudyHub تعمل عبر GitHub Pages. الواجهة باللغة العربية وتدعم الهاتف والكمبيوتر.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub واجعله `Public` إذا أردت استخدام GitHub Pages المجاني دون قيود خاصة.
2. ارفع محتويات هذا المجلد إلى جذر المستودع. يجب أن يكون `index.html` في الجذر، وليس داخل مجلد إضافي.
3. افتح `Settings` ثم `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط `Save`.
6. انتظر اكتمال النشر. سيظهر رابط الموقع في صفحة Pages.

## ما الذي يعمل في هذه النسخة؟

- واجهة متجاوبة للموبايل والكمبيوتر.
- إضافة المواد والمهام والملاحظات ومواعيد المذاكرة وتعديلها وحذفها.
- حفظ البيانات في المتصفح باستخدام localStorage.
- حفظ ملفات صغيرة في المتصفح وتنزيلها.
- تصدير نسخة احتياطية واستيرادها يدويًا.
- مساعد تنظيم مذاكرة بسيط يعمل محليًا، وليس نموذج ذكاء اصطناعي متصلًا.
- يمكن تثبيت الموقع كتطبيق ويب من المتصفح إذا كان المتصفح يدعم ذلك.

## حدود مهمة

GitHub Pages يستضيف ملفات ثابتة فقط. هذه النسخة لا تحتوي على خادم Python أو قاعدة بيانات مشتركة أو تسجيل دخول آمن أو مزامنة بين الأجهزة أو مساعد ذكاء اصطناعي حقيقي.

البيانات والملفات تُحفظ في المتصفح والجهاز الحالي فقط. فتح الموقع من موبايل آخر لا يجلب تلقائيًا بيانات اللابتوب. لنقل بياناتك بين الأجهزة استخدم `نسخة احتياطية` ثم `استعادة نسخة` على الجهاز الآخر.

لا تحفظ معلومات حساسة في هذه النسخة، ولا تعتبرها خزنة ملفات آمنة. أي شخص يزور رابط الموقع يمكنه تنزيل كود الواجهة؛ لا تضع مفاتيح API أو كلمات مرور أو بيانات خاصة داخل ملفات GitHub.

## ملفات المشروع

- `index.html`: صفحة الموقع.
- `assets/style.css`: التصميم المتجاوب.
- `assets/app.js`: وظائف الموقع والحفظ المحلي.
- `manifest.webmanifest` و`sw.js`: دعم التثبيت والعمل دون اتصال بعد الزيارة الأولى في المتصفحات الداعمة.
